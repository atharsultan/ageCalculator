# Age Calculator

A simple web-based **Age Calculator** built with HTML, CSS, and JavaScript.  
It calculates a person’s exact age in **years, months, and days** based on their birth date.

## Features
- Enter your birth date (day, month, year)
- Calculates exact age with years, months, and days
- Handles leap years correctly
- Simple and clean UI

## Usage
1. Enter your **birth date**.
2. Click the **Calculate Age** button.
3. Your age will be displayed instantly.
